# Sales Time Series Forecasting

Time series analysis and forecasting of sales data developed as the capstone project for the MBA in Data Science and Analytics at **USP/Esalq**.

The project investigates sales volume and revenue over time, prepares an operational sales dataset, explores temporal patterns, and compares statistical and machine-learning forecasting approaches.

## Project objectives

- Understand and clean the original sales dataset.
- Explore distributions, outliers, correlations, trends, and seasonality.
- Build monthly and annual time series for sales and revenue.
- Compare Naive, Holt-Winters, ARIMA/SARIMA, and XGBoost forecasts.
- Evaluate models using MAE and RMSE.

## Getting started

Python 3.12 is recommended.

```bash
git clone https://github.com/Marinopl/TimeSeriesAnalysis_MBA-USP.git
cd TimeSeriesAnalysis_MBA-USP

python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows PowerShell
# .venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
pip install -r requirements.txt
jupyter lab
```

Run the notebooks in numerical order. Each notebook resolves paths relative to the repository root and writes its processed output to `data/interm/`.

## Data pipeline

1. **Data understanding** reads `data/raw/data.csv`, validates types and missing values, removes invalid records, and writes `data/interm/data_1.csv`.
2. **EDA** investigates the cleaned data and writes `data/interm/data_2.csv`.
3. **Temporal analysis** creates calendar features and time-series aggregates, writing `data/interm/data_3.csv`.
4. **Predictive models** evaluates classical forecasting methods on monthly revenue.
5. **XGBoost** evaluates lag-based regression features for the same forecasting task.

The source dataset contains product, description, unit price, quantity, total value, sale date, cost price, inventory balance, and product group fields. The original Portuguese column names are retained to preserve the data contract.

## Reproducibility notes

- Execute notebooks with the repository as the working directory, or use the path-aware setup cells included in each notebook.
- The final two notebooks use data generated by the first three notebooks.
- Figures follow a consistent visual style inspired by the MBA project guidelines.
- Generated notebook outputs are intentionally kept in the notebooks for academic review; rerunning a notebook will refresh them.
